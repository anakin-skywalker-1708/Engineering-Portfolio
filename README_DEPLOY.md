# Updated Engineering Portfolio Website

This is a standalone GitHub Pages replacement for the current portfolio site. It includes a new Knuckey Rover gallery and the RMIT EnGenius 2026 prize.

## Deploy
1. In `anakin-skywalker-1708/Engineering-Portfolio`, upload **the contents of this folder** to the repository root, replacing `index.html` and adding `style.css` and `assets/rover/`.
2. Keep the existing `assets/` files for other projects; do not delete them.
3. GitHub Pages will redeploy from `main` / `(root)`.

**Note:** The previous website ZIP was not supplied in this turn. Therefore this is a redesigned standalone replacement, not a byte-for-byte edit of the old site. The existing rocket, gripper and CLS media are not included in this ZIP. Add them from the old site's `assets/` folder when publishing.
